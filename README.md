# Smashio

> 一个关于 AI、产品和正在发生的事情的个人主页。

你好，我是 Yichen，一名墨尔本大学计算机与软件系统背景的 AI 产品 builder。

我喜欢把技术和真实生活里的问题放在一起思考：模型到底能不能帮人完成一件事？一个想法怎样从 demo 变成产品？AI 除了写代码，还能不能让学习、求职和日常工作变得更轻松？

这个仓库是我的个人网站，也是一本持续更新的数字笔记本。这里记录项目、研究、踩坑，以及那些让我觉得“这个东西也许真的有用”的瞬间。

## 我在关注什么

- AI 产品策略与真实应用场景
- LLM、Agent、RAG 和模型工具调用
- 数据驱动的产品增长与用户体验
- 把复杂技术做成普通人愿意使用的产品
- 学生、求职者和小团队如何更低成本地使用 AI
